# 商场会员小程序后台管理系统

## 项目简介

这是一个基于云开发的商场会员小程序后台管理系统，采用深色奢华风格设计，提供会员管理、优惠券管理、积分商品管理和数据统计等功能。

## 功能特性

### 1. 数据概览
- 会员总数统计
- 总积分发放统计
- 优惠券领取统计
- 今日兑换统计
- 会员增长趋势图表
- 积分使用情况图表
- 最近活动列表

### 2. 会员管理
- 会员列表查看
- 会员等级筛选
- 会员搜索
- 会员数据导出
- 积分调整

### 3. 优惠券管理
- 优惠券列表
- 创建优惠券（折扣券/代金券）
- 设置使用门槛和有效期
- 库存管理

### 4. 积分商品
- 商品列表展示
- 添加积分兑换商品
- 设置所需积分和库存
- 商品上下架管理

### 5. 交易记录
- 积分变动记录
- 优惠券领取记录
- 商品兑换记录
- 按类型筛选

## 技术栈

- **前端**: HTML5 + Tailwind CSS + JavaScript
- **图表**: Chart.js
- **图标**: FontAwesome 6
- **字体**: Playfair Display, Source Sans Pro, JetBrains Mono
- **后端**: CloudBase (云开发)
- **数据库**: CloudBase NoSQL

## 设计风格

- **主题**: Luxury/Refined (奢华精致)
- **配色**:
  - 主背景: #1a1a2e (深邃蓝黑)
  - 卡片背景: #16213e (深蓝)
  - 强调色: #d4af37 (金色)
  - 文字: #ffffff (白色) / #a0a0a0 (灰色)
- **布局**: 侧边导航 + 主内容区，响应式设计

## 快速开始

### 1. 部署到云开发静态托管

```bash
# 进入项目目录
cd admin

# 部署到云开发静态托管
# 使用云开发控制台或 CLI 工具上传文件
```

### 2. 配置数据库

确保云开发数据库中已创建以下集合：
- `members` - 会员信息
- `coupons` - 优惠券
- `user_coupons` - 用户优惠券
- `point_products` - 积分商品
- `point_records` - 积分记录

### 3. 访问后台

部署完成后，通过静态托管域名访问：
```
https://<your-env-id>.tcloudbaseapp.com/admin/
```
