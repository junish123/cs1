# 商场会员管理系统 - 后台管理页面

## 项目概述

这是一个基于云开发的 Web 后台管理页面，用于管理商场会员小程序的数据。

## 功能特性

### 1. 数据概览
- 总会员数统计
- 今日新增会员
- 总积分发放量
- 优惠券领取统计
- 最近注册会员列表

### 2. 会员管理
- 会员列表查看
- 会员等级显示
- 积分余额查看
- 积分调整功能

### 3. 优惠券管理
- 创建新优惠券
- 查看优惠券列表
- 上架/下架优惠券
- 支持折扣券和代金券

### 4. 积分商品管理
- 添加积分兑换商品
- 管理商品库存
- 上架/下架商品

### 5. 兑换记录
- 积分兑换记录
- 优惠券领取记录
- 按时间排序展示

## 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **UI 框架**: Tailwind CSS
- **图标库**: FontAwesome 6
- **字体**: Google Fonts (Playfair Display, Source Sans Pro, JetBrains Mono)
- **后端**: CloudBase (云开发)
- **数据库**: CloudBase NoSQL 数据库

## 设计风格

- **风格**: Luxury/refined (奢华精致)
- **主色调**: 深蓝黑 (#1A1A2E) + 珊瑚红 (#E94560)
- **布局**: 左侧固定导航 + 右侧主内容区
- **响应式**: 适配 PC 和移动端
